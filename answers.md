\# Відповіді на питання



1\. Чому важливо вказувати user.name та user.email?



Це ім’я та пошта автора комітів. Git записує їх, щоб було видно, хто зробив зміни.



2\. Яка різниця між git pull і git fetch?



git fetch завантажує інформацію та зміни з віддаленого репозиторію, але не додає їх у поточну гілку. git pull завантажує зміни й одразу поєднує їх із поточною гілкою.



3\. Як скасувати останній коміт, не втрачаючи зміни у файлах?



Виконати команду:



git reset --soft HEAD\~1



Останній коміт скасується, але зміни залишаться у файлах і будуть підготовлені до нового коміту.
